# MIT 8103 Advanced Database Systems — Portfolio

This repo contains my coursework for MIT 8103 Advanced Database Systems at MIVA Open University.

Case study: **ThreadHaus**  a simulated online clothing store.

## Folders

- `portfolio-1-database-design`  ER diagram, schema, DDL scripts
- `portfolio-2-query-optimisation`  SQL queries, execution plans, index analysis
- `portfolio-3-transactions-concurrency`  transaction scripts, isolation level tests
- `portfolio-4-nosql`  NoSQL design and comparison
- `portfolio-5-distributed-cloud`  distributed and cloud database work
